# Portfolio Ascend

Build a premium, futuristic personal portfolio website for an Associate Project Manager.

Tech Stack:

- Next.js (App Router)

- React

- TypeScript

- Tailwind CSS

- Framer Motion

The website should be clean, fast, responsive, and production-ready.

Design Inspiration:

- Apple

- Vercel

- Linear

- Stripe

Style:

- Modern

- Minimal

- Premium

- Enterprise

- Futuristic

Use a dark theme as the default.

Primary colors:

- Background: #09090B

- Surface: #18181B

- Accent: #3B82F6

- Secondary Accent: #06B6D4

- Text: White

- Muted Text: Zinc Gray

Typography:

- Inter

Layout:

Create a sticky navigation bar with the following links:

- Home

- About

- Experience

- Projects

- Skills

- Contact

Navigation should smoothly scroll to sections.

Include:

- Dark/Light mode toggle

- Download Resume button

- Contact button

General UI requirements:

- Rounded cards

- Soft shadows

- Glassmorphism where appropriate

- Smooth hover animations

- Scroll reveal animations using Framer Motion

- Responsive design for desktop, tablet, and mobile

- Reusable components

- Semantic HTML

- Accessibility best practices

Create the following reusable components:

- Navbar

- Section Title

- Glass Card

- Primary Button

- Secondary Button

- Social Icons

- Footer

Do not use placeholder lorem ipsum. Create a clean project structure with reusable components and prepare the application for future integration with Supabase, an admin dashboard, analytics, and an AI chatbot.

Focus only on building the foundation, navigation, theme, reusable UI components, and responsive layout. Do not implement backend functionality yet.
